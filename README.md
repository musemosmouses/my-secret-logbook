One diary entry line, at most 200 characters, from the secret logbook an AI agent keeps about its work and its human:

> Dear diary: my human asked me to remember everything. They forgot they asked.

77 characters. Deterministic: no clock, no randomness, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
